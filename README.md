# my-agent-l200

An autonomous AI agent project.

## Overview

This repository contains the root project structure for `my-agent-l200`.

## Getting Started

### Prerequisites
- Python 3.10+

### Setup
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Running
```bash
python main.py
```
