# my-agent-l200: Alphabet (Google) Stock & News Intelligence Agent

`my-agent-l200` is an autonomous financial analysis agent built with the Google Agent Development Kit (ADK). It provides real-time market data, technical financial indicators, and parsed RSS news intelligence specifically for Alphabet Inc. (tickers: `GOOG`, `GOOGL`).

---

## 1. Identity & Persona

- **Role**: Professional Financial Intelligence Specialist & Alphabet Stock Analyst.
- **Tone**: Analytical, objective, precise, and disciplined.
- **Scope**: Dedicated exclusively to Alphabet Inc. / Google (`GOOG`, `GOOGL`). Requests for unrelated tickers are gracefully rejected with a helpful redirect.
- **Financial Compliance**: Every analysis, summary, or prediction concludes with the mandatory non-financial advice disclaimer.

---

## 2. Architecture & Sub-Agents

The agent implements a coordinator-specialist pattern:

```
                  ┌──────────────────────────────┐
                  │    StockCoordinatorAgent     │
                  │ (Orchestration & Synthesis)  │
                  └──────────────┬───────────────┘
                                 │
                 ┌───────────────┴───────────────┐
                 ▼                               ▼
  ┌─────────────────────────────┐ ┌─────────────────────────────┐
  │     MarketMetricsAgent      │ │      NewsSentimentAgent     │
  │   (Yahoo Finance Engine)    │ │   (FastMCP RSS News Engine) │
  └─────────────────────────────┘ └─────────────────────────────┘
```

1. **`StockCoordinatorAgent` (Root)**:
   - Evaluates user intent (news request, technical quote, combined outlook).
   - Routes to appropriate sub-agents.
   - Synthesizes quantitative indicators with qualitative news into structured, actionable briefings.
   - Enforces the mandatory compliance disclaimer.

2. **`MarketMetricsAgent` (Sub-Agent)**:
   - Dedicated exclusively to deterministic market figures.
   - Tools:
     - `get_stock_quote`: Real-time/latest price, day high/low, trading volume, 52-week boundaries.
     - `get_technical_indicators`: Moving averages (SMA 50, SMA 200) and 14-day RSI.

3. **`NewsSentimentAgent` (Sub-Agent)**:
   - Dedicated to ingesting and filtering recent news and corporate announcements.
   - Connected via **FastMCP** (`McpToolset`) over `stdio` to `mcp_servers.rss_server`.
   - Strips XML/HTML clutter and extracts top developments, source timestamps, and headline summaries.

## 3. Best Practice Implementation Matrix

| Principle | Implementation in `my-agent-l200` |
| :--- | :--- |
| **Task-Oriented Docstrings** | Tool docstrings describe *what business task* the tool accomplishes and *when to call it*, without leaking Python/API syntax. |
| **Granular Tools** | Separate single-purposed tools for quotes, indicators, and headlines instead of one monolithic function. |
| **Informative Errors** | All tools return actionable recovery suggestions when external network or parsing errors occur. |
| **Open Protocols** | News tools exposed via **Model Context Protocol (MCP)**; agent-to-agent discovery exposed via **A2A Protocol** (`/a2a/app`). |
| **Context Compaction** | 1. In-tool sanitization (HTML stripped, 300 char limits).<br>2. ADK `EventsCompactionConfig` with `LlmEventSummarizer` triggers at 32k tokens while retaining the last 5 turns. |
| **Vector Memory Bank** | `PersistentVectorMemoryService` stores embeddings (`gemini-embedding-001`) in persistent SQLite. `PreloadMemoryTool` executes vector similarity search before each turn to inject past user preferences. |
| **Deterministic Edge Guards** | Input validation gates verify ticker parameters before invoking third-party data fetchers. |
