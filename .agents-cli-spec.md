# Agent Spec: my-agent-l200

## Overview
A professional public stock information and analysis agent focusing on Google (Alphabet Inc. - tickers `GOOG` / `GOOGL`). The agent gathers recent RSS news feeds, extracts key market signals, calculates technical financial metrics (moving averages, RSI, price action) via Yahoo Finance, and synthesizes data into comprehensive summaries, trend predictions, and risk disclosures. It exposes a local FastAPI / ADK Web Playground interface and supports inter-agent communication via the A2A protocol.

## Language
`python`

## Architecture & Sub-Agents
Coordinator-Specialist Multi-Agent Pattern:
- **`StockCoordinatorAgent`**: Orchestrates user requests, enforces financial safety disclaimers, routes tasks to sub-agents, and synthesizes technical indicators with news sentiment.
- **`MarketMetricsAgent`**: Specialized sub-agent with single-purposed, granular tools for fetching Yahoo Finance market data and calculating technical indicators (SMA 50, SMA 200, RSI 14).
- **`NewsSentimentAgent`**: Specialized sub-agent utilizing an MCP-compliant RSS feed connector to ingest and summarize Google/Alphabet company news and Investor Relations updates.

## Example Use Cases
1. **Combined Analysis**: *"Summarize the latest Google news and tell me how the 50-day and 200-day moving averages look."*
   - Output: Structured summary of top recent headlines, technical moving average breakdown (Golden Cross / Death Cross signal), and synthesized market outlook with disclaimer.
2. **On-Demand Technicals**: *"What are the current price, RSI, and volume metrics for GOOGL?"*
   - Output: Formatted key statistics table with overbought/oversold indicator status.
3. **News Sentiment & Outlook**: *"What are the key recent developments for Alphabet and what is the near-term expectation?"*
   - Output: Grouped bulleted news summaries, sentiment rating (Bullish/Neutral/Bearish), and scenario-based projections.

## Tools Required
- **`get_stock_quote`**:
  - *Purpose*: Retrieves the latest real-time/delayed market quote (price, change, high, low, volume) for Google/Alphabet.
  - *API*: Yahoo Finance (`yfinance` / public endpoint).
  - *Auth*: None (public endpoint).
- **`get_technical_indicators`**:
  - *Purpose*: Computes moving averages (SMA 50, SMA 200) and relative strength index (RSI 14) over specified historical lookback windows.
  - *API*: Yahoo Finance historical price series.
  - *Auth*: None.
- **`fetch_google_news_rss`**:
  - *Purpose*: Fetches, cleans, and parses recent Google/Alphabet news and press releases from RSS feeds via a dedicated local FastMCP tool server (`mcp_servers/rss_server.py`).
  - *API*: Public Google News RSS & Alphabet Investor Relations RSS feeds parsed and served via FastMCP (`McpToolset`).
  - *Auth*: None.

## Constraints & Safety Rules
- **Non-Financial Advice Disclaimer**: Every response providing predictions or analytical outlooks MUST include the mandatory disclaimer: *"Disclaimer: This analysis is for informational purposes only and does not constitute financial, investment, or trading advice."*
- **Granular Single-Purposed Tools**: Tools must execute one specific action and return structured data with actionable error messages for LLM self-correction.
- **Task-Oriented Docstrings**: Python tool docstrings must describe what task the tool accomplishes and when it should be invoked, without exposing implementation mechanics.
- **Scope Restriction**: Hard gate on symbol inputs to prevent arbitrary stock lookups beyond Google/Alphabet (`GOOG`, `GOOGL`) in the initial slice.
- **Context Compaction**: Keep raw RSS feed payload text out of long-term dialogue history using turn truncation or summarization.
